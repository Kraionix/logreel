# logreel

Typed, allocation-free event logging for Rust services, with an append-only
binary segment format that other programs can read without your codec.

`logreel` is a record pipeline, not a formatting framework:

- **Typed events.** One `Event` type per process, a `u16` kind per variant,
  `encode`/`decode` generated by `#[derive(Event)]`.
- **Cheap when disabled.** The level and category are checked before the
  payload is built; a disabled call allocates nothing and does not format.
- **A projection, not a second stream.** Text lines and the record stream are
  produced from the same values on the writer thread.
- **A format, not a log crate.** Segments carry a 56-byte header, CRC-framed
  batches and a compact envelope. `probe` works without any codec; readers
  stream and never copy the file.
- **One writer, many producers.** A bounded channel, drop-and-count on
  overflow, and a clean shutdown that drains.

## Example

```rust,no_run
use logreel::{Event, Level, Settings, init};

#[derive(Event)]
#[event(kind = 0, codec = "prost")]
struct SessionClosed {
    #[prost(uint64, tag = "1")]
    bytes_out: u64,
}

impl logreel::Render for SessionClosed {
    fn render(&self, out: &mut String) {
        use std::fmt::Write as _;
        let _ = write!(out, "session closed, bytes_out={}", self.bytes_out);
    }
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let settings = Settings::builder()
        .min_level(Level::Info)
        .domain(b"dc=1")
        .build();
    let logger = init::<SessionClosed>(settings, None, Box::new(logreel::file::FileStore::open("./logs")?))?;
    let handle = logger.handle();
    handle.emit(Level::Info, 0, 0, 7, SessionClosed { bytes_out: 1024 });
    logger.shutdown();
    Ok(())
}
```

The full working example is in [`examples/quickstart`](examples/quickstart).
The byte layout is specified in [`docs/SPEC.md`](docs/SPEC.md); a reader in
another language can follow [`docs/FORMAT.md`](docs/FORMAT.md).

## Format promise

- A segment is either fully valid frames or a torn tail; a reader stops at the
  first invalid frame and reports its offset. It never resynchronises.
- Unknown kinds and unknown schemas degrade to raw output, never to a refused
  file.
- Any change to the bytes requires a format version bump, a new fixture
  directory, and an ADR amendment in the same change.

## Features

| feature | default | effect |
|---|---|---|
| `text` | off | text projection on stderr/stdout |
| `ring` | off | in-memory ring for post-mortem dumps |
| `file` | off | append-only segment backend |
| `zstd` | off | per-frame compression (implies `file`) |
| `redb` | off | alternative redb backend |

Text is off by default so a published dependency does not pull a formatting
stack into a binary that only needs records.

## Status

`0.1.0`. The public API is frozen at the format boundary; the format itself
is versioned and the fixture set in `fixtures/v1` is normative.
